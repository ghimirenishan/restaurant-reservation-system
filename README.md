# restaurant-reservation-system
An Agile project management and software engineering simulation: planning, requirements analysis, system design, and testing for a web-based restaurant table reservation system — no application code, by design. Project management was run in Trello; all planning, requirements, design, and testing documentation is version-controlled here in GitHub.

Project Overview

The system is designed to replace a restaurant's manual, phone-based reservation process with a centralized digital platform connecting customers, hosts, kitchen staff, and management. Core capabilities include:

Table Search & Booking — customers search and reserve tables by date, time, and party size
Host Dashboard & Live Table Status — real-time view of the day's reservations and table availability
Reservation & Account Management — customers can modify/cancel bookings and view reservation history
Reporting & Analytics — manager visibility into reservation volume, peak hours, and staffing needs
Methodology

Built using Scrum, run across two one-week sprints in Trello, with a 10-item product backlog prioritized by MoSCoW (Must/Should/Could) and estimated in Fibonacci story points. See /requirement for the full justification and process documentation.

Requirements

Functional and non-functional requirements, stakeholder analysis, and requirements-gathering methodology (interviews, questionnaires, observation, document analysis, brainstorming) are documented in /requirement.

Design

Four UML diagrams model the system from complementary perspectives — Use Case, Class, Sequence, and Activity — each traceable back to specific functional requirements. See /Design.

Testing

33 test cases spanning Unit, Integration, System, and User Acceptance Testing (UAT), covering both positive and negative scenarios, with a full requirements-to-test-level traceability matrix. See /Testing.

Project Management

Product backlog, Sprint 1, and Sprint 2 boards were maintained in Trello with story points, priorities, WIP limits, and role-based task assignment. Board screenshots are in /treelo board.
